# 投资报告生成链路审计

审计日期：2026-10-30。范围为输入、研究与分析、事实纠正、计算和报告导出。本记录关注报告质量，没有运行付费模型；状态以本次审阅代码及下列复现为准。

## 数据链路补全

已增加公共原文快照与SQLite FTS5/BM25检索：URL、完整提取正文、首次归档时间、SHA256、稳定快照ID和分块位置均可保存；实际工具调用search_knowledge/read_source可离线回放。模型没有实际读到的归档内容不能充当已读证据。未上全站爬虫、向量库、GraphRAG或一整套新框架。详见[data_sources_and_rag.md](data_sources_and_rag.md)。

本轮135项测试通过，网页演示无异常、三个下载入口正常；世界银行公开接口原文归档后在断网条件下回读、哈希及同源摘录匹配通过。未调用付费模型进行新一轮完整真实公司研究。正式渲染同时移除未读引用支撑的原句，保留已读来源的出处，避免出现悬空引用；评分引用仅指向保留证据。

## 已核实修复及正确行为

- `None` 表示未知退出估值；`0` 表示全损，当前 `financials.calculate_returns` 正确计算 MOIC 为 0、简化年化 IRR 为 -100%。
- 用户未提供情景权重或持有年数时不自动补值；期望倍数按用户主观权重计算，没有计算概率加权 IRR。
- 经营数据使用 USD 百万美元、明确统计期间及逐项来源；入口拒绝未知键、非数值、非有限值和不可能的负期末存量 ARR。
- 先前“期望倍数不可算提示遗漏本轮投后估值”和“IRR 不可计算时写未提供”的显示问题已修正。

## 上游定位函数的边界

`affected_materials(materials, claims)` 只对完整主张文本去除空白后进行包含匹配，或匹配材料 `evidence` 数组记录内的 `evidence_id`。它不因来源 URL 一样而推断为同一事实，也不根据大致相近的数字猜定位；排除主席自身，并去除同一材料中的重复主张。

该函数不能可靠定位改写后的同义句、跨多个字段拼合的句子，或未记录证据编号的间接推论。文本不匹配且缺少证据 ID 时应保留定位失败的内部记录，不能据此宣称全部相关材料已纠正。正式报告需要用纠正后的材料重新生成，再通过发布回归检查。
