# 10 分钟演示脚本

目标：展示从赛道配置到报告、证据、核查和修正的完整流程。演示模式使用模拟数据，只验证流程和界面，不代表真实公司的事实或投资结论；联网运行会产生模型和搜索费用，完成时间也受模型服务影响。

## 演示前准备

1. 在项目目录安装依赖：`pip install -r requirements.txt`。
2. 使用 `streamlit run app.py` 启动网页，选择演示模式和 AIGC 内容赛道，准备 3 家演示公司。演示不需要填写 API 密钥。
3. 打开 [总体架构](architecture.md) 和 [验证记录](validation.md)。如要展示真实草稿，提前打开验证记录中链接的具身智能草稿，并说明其核查未完成。

## 时间安排

| 时间 | 操作和讲解 |
| --- | --- |
| 0:00–1:00 | 展示架构图：输入与配置、研究与证据、分析与比较、辩论与核查、决策与交付。说明研究员和核查员可使用联网工具，其他角色消费前序结果。 |
| 1:00–2:00 | 在网页选择赛道，介绍公司名称、官网、可选 BP 和投后估值。说明赛道配置包含评分维度和权重，角色模型在配置文件中选择。 |
| 2:00–3:00 | 运行演示模式，展示进度与报告。明确演示结果是占位数据，不用于说明真实研究质量。 |
| 3:00–4:30 | 展示公司评分、加权排序、TOPSIS 和单维度敏感性；解释低置信度或缺少关联独立来源时的评分假设范围，并说明范围不是统计置信区间。 |
| 4:30–6:00 | 展示来源、证据编号和事实核查。说明编号匹配仅表示来源条目存在；“公司口径”与独立支持分开列示，每轮最多抽查 15 条主张。 |
| 6:00–7:00 | 展示默认一轮多空观点与可选第二轮。解释工具原文与摘录匹配、不实主张退回修正和逐条复查；引用匹配不能证明语义支持，核查也可能遗漏主张。 |
| 7:00–8:00 | 展示主席结论、风险、尽调清单和退出情景。说明回报倍数使用投后估值、退出估值和后续稀释假设，缺少投后估值时不计算，且不等同于 IRR。 |
| 8:00–9:00 | 下载 Markdown 和 JSON；展示 JSON 中的结构化证据、核查历史、修正前后材料和运行指标。 |
| 9:00–10:00 | 打开验证记录，说明自动化测试、小样本核查和真实草稿各自验证了什么，以及真实案例在耗时和完整核查上的未通过项。 |

## 真实模式补充说明

配置可用 API 凭据后可在网页选择真实模式；建议事先运行并保存结果，现场展示真实报告和运行记录。真实运行不能保证在演示时间内完成，也不能将核查未完成的草稿称为验收通过的示范报告。成本应以实际服务商计费为准，接口未返回的费用不能视为零。
