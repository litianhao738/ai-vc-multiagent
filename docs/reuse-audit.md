# 投研框架与复用情况

核对日期：2026-10-30。本文区分报告格式参考、本项目代码实现和仅列入参考资料的外部项目。

## 报告风格

参考 Bessemer Venture Partners 公开的 [Shopify A 轮](https://www.bvp.com/memos/shopify) 和 [Wix 种子轮](https://www.bvp.com/memos/wix)投资备忘录，报告结论部分前置展示推荐、投资要点、主要风险及优先核实事项。它们是单家公司投资备忘录；本项目还需要比较多家公司，因此保留赛道与横向比较章节。项目没有照搬原文，也没有因为参考这些案例就生成不存在的交易条款。

报告仍为七部分 Markdown，完整理由和证据保留在后续章节与附录；前置要点最多列出各类的前三条。报告长短取决于模型生成的内容，没有页数或字数的硬性约束。[旧具身智能草稿](../outputs/validation/embodied-ai_20261029_040937/report.md)在此次调整前生成且事实核查不完整，不代表新格式或通过验收的报告。

## 项目里实际执行的内容

| 内容 | 具体实现 | 边界 |
| --- | --- | --- |
| 赛道评分 | `sectors/*.yaml` 定义团队、市场、产品、竞争、商业化和风险等维度与权重；公司分析师依据标准给分。 | 分数由模型判断，权重是配置，不保证评分或排名正确。 |
| 加权评分与 TOPSIS | `vcagents/scoring.py` 本地计算；加权分用于排序，TOPSIS 用于对照和同分时辅助排序。 | 本地实现，没有接入 pyDecision；两种方法使用相同的模型分数，不能互相证明输入真实。 |
| 排名敏感性 | 代码逐次将一家公司一个维度的评分加或减 1 分，观察首位是否改变。 | 只覆盖这一类单维度变化，不是概率预测。 |
| 信息不足的分数范围 | 对低置信度或没有关联独立来源的维度按 1–10 分计算假设范围。 | 来源性质由模型识别，来源编号匹配不代表事实已核实；范围不是统计置信区间。 |
| 两两比较与多空辩论 | 默认一轮多空观点；正反顺序两两比较与第二轮辩论可选开启。 | 使用本项目自己的流程和提示词，不等于接入 RankGPT 或 TradingAgents。 |
| 事实抽查与修正 | 工具原文留痕、同源摘录与主张数字核对；明确错误和缺少支持的事实都补查、更正或删除并复查，主席问题能回传上游。 | 每轮最多抽查15条；数值门槛不推测单位，摘录存在不能证明语义支持，仍依赖模型判断及原始资料。正式报告与内部audit分开。 |
| 原文快照与RAG检索 | 实际接入标准库SQLite FTS5/BM25、中文二元词、原文分块与回读；记录URL、时间、hash、快照和offset。 | 没有接入LangChain/LlamaIndex或向量库；检索不等于事实验证，历史版本不能代表当前状态。见[data_sources_and_rag.md](data_sources_and_rag.md)。 |
| 回报与经营测算 | `financials.py` 按结构化输入计算经营和市场指标、MOIC、无中间现金流的简化年化 IRR，以及用户权重下期望倍数。 | 原始输入和情景权重需要用户提供；不包含完整交易条款、费用与税费，来源说明不等于已独立核实。 |
| 市场与公司研究 | 提示词要求从上往下和从下往上估算市场，并检查产品、团队、融资、客户及赛道指标。 | 这是研究要求，不是自动化财务模型；缺少依据的事实删去，客观信息缺口可说明；没有证据不能自行断言公司未披露。 |
| 历史案例汇总 | `backtest.py` 汇总已有报告首选公司的后续融资、收购或倒闭事件。 | 尚无完成验收的真实历史回测；该工具不限制搜索的时间范围，不能自动排除事后信息，也不计算投资收益。 |

## 尚未接入的外部资源

- **Anthropic Financial Services 的 `ic-memo`、`sector-overview`、`deal-screening`、`unit-economics` 等 Skill**：项目书列为参考，运行时没有加载这些 Skill；角色使用项目自己的 `vcagents/roles.py` 提示词。
- **SAFE、Loki、fact-check-workflow**：本项目没有调用其代码或完整 Skill。让模型自报证据缺口的一致性试验未接入正式流程；当前新增的是代码检查工具实际原文，而非重新包装该失败试验。见 [报告质量说明](report_quality.md)。
- **GPT-Researcher、STORM、TradingAgents、RankGPT**：列为研究、多视角、辩论或排序参考；项目没有把它们作为依赖或运行时组件接入。
- **pyDecision 与 AHP**：本地有 TOPSIS 实现，但没有依赖 pyDecision；项目书提到 AHP，当前代码没有实现 AHP。

这些资源及链接集中列在 [README 的外部资源栏](../README.md#可复用的外部资源)。Python 依赖见 `requirements.txt`。模型和联网搜索通过配置的 API 实际调用；使用演示模式时不调用真实模型或搜索。

## 验证状态

自动化测试主要验证流程与计算，演示数据不是投资研究。2026-10-29 最新三家公司真实运行在主席调用时遇到 HTTP 402，未生成完整报告；研究阶段抽查结果和人工发现的口径问题见 [验证记录](validation.md)。尚不能根据这些检查宣称报告已通过项目书的完整质量、时效和历史回测验收。
